# Transform Data Using Spark API

### Prerequisite

```python
import json

schemas_text = spark.read.text(
    "/Volumes/workspace/default/retail_db/retail_db/schemas.json",
    wholetext=True
).first().value

columns_detail = json.loads(schemas_text)["orders"]
columns = [
    col["column_name"]
    for col in sorted(columns_detail, key=lambda col: col["column_position"])
]
```

### Read the data

```python
orders = (
    spark.read
         .option("inferSchema", True)
         .csv("/Volumes/workspace/default/retail_db/retail_db/orders/")
         .toDF(*columns)
)
```

### Simple transform

```python
from pyspark.sql.functions import col, count

(orders
    .groupBy("order_status")
    .agg(count("*").alias("order_count"))
    .orderBy(col("order_status").desc())
    .show()
)
```
