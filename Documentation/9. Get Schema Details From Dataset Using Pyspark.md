# Get Schema Details for All Datasets Using PySpark

This example reads `schemas.json`, gets the column names for a dataset, and prints them for several datasets.

## 1. Read the dataset names

```python
import json

base_dir = "/Volumes/workspace/default/retail_db/retail_db"
schemas_file = f"{base_dir}/schemas.json"

schema_text = spark.read.text(schemas_file, wholetext=True).first().value
schema_data = json.loads(schema_text)

schema_data.keys()
```

`json.loads()` converts the JSON text into a Python dictionary. Its keys are the dataset names.

## 2. Create a function to get column names

```python
def get_columns(schemas_file, ds_name):
    schemas_text = spark.read.text(schemas_file, wholetext=True).first().value
    columns_detail = json.loads(schemas_text)[ds_name]
    sorted_columns = sorted(
        columns_detail,
        key=lambda col: col["column_position"]
    )
    return [col["column_name"] for col in sorted_columns]
```

The function takes the path to `schemas.json` and a dataset name. It reads that dataset's column details, sorts them by `column_position`, and returns the column names in order.

## 3. Test the function

```python
get_columns(schemas_file, "orders")
```

The result is a list of column names for `orders`.

## 4. Get column names for all selected datasets

```python
ds_list = [
    "departments",
    "categories",
    "orders",
    "products",
    "customers",
    "order_items",
]

for ds in ds_list:
    print(f"Processing {ds}")
    columns = get_columns(schemas_file, ds)
    print(columns)
```

The loop processes each dataset name, calls `get_columns()`, and prints that dataset's columns.
