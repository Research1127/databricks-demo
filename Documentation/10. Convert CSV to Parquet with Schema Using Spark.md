# Convert CSV to Parquet with Schema Using Spark

This walkthrough first tests the conversion with the `orders` dataset. After checking the result, it applies the same steps to several datasets.

## Test the `orders` dataset first

### Get the column names

The `get_columns` function reads `schemas.json` and returns the column names for the selected dataset in the correct order.

```python
base_dir = '/Volumes/workspace/default/retail_db/retail_db/'
columns = get_columns(f'{base_dir}/schemas.json', 'orders')
```

### Read the CSV data

```python
orders = spark.read.csv('/Volumes/workspace/default/retail_db/retail_db/orders',inferSchema=True).toDF(*columns)
```

- `spark.read.csv(...)` reads the CSV files from the `orders` folder.
- `inferSchema=True` asks Spark to infer the data types from the values.
- `.toDF(*columns)` assigns the column names from the `columns` list to the DataFrame.

### Check the DataFrame

```python
orders.printSchema()
orders.show(5, truncate=False)
```

`printSchema()` shows the column names and types. `show()` previews five rows so you can check that the CSV was read as expected.

## Create the Parquet output

```python
orders. \
   write. \
   mode('overwrite'). \
   parquet('/Volumes/workspace/default/retail_db/retail_db_parquet/orders')
```

This writes the `orders` DataFrame in Parquet format to the `orders` folder under `retail_db_parquet`. The `overwrite` mode replaces existing output at that destination if you run the cell again.

Spark may create multiple `part-...parquet` files in that folder. This is expected.

## Check that the Parquet files were created

Run this in a Databricks notebook cell:

```text
%fs ls /Volumes/workspace/default/retail_db/retail_db_parquet/orders
```

You should see the output files. `%fs ls` is a Databricks notebook command, not a Mac Terminal command.

## Query the Parquet data

Run this in a SQL notebook cell:

```sql
SELECT * FROM PARQUET.`/Volumes/workspace/default/retail_db/retail_db_parquet/orders`
```

This reads the Parquet files from the output folder as a table-like result.

## Convert all selected datasets

The loop below repeats the same process for each dataset in `ds_list`: get its column names, read its CSV folder, assign the column names, and write the result to its own Parquet folder.

```python
base_dir = '/Volumes/workspace/default/retail_db/retail_db'
tgt_base_dir = '/Volumes/workspace/default/retail_db/retail_db_parquet'
ds_list = ['departments', 'categories', 'orders', 'products', 'customers', 'order_items']

for ds in ds_list:
   print(f'Processing {ds} to parquet')
   columns = get_columns(f'{base_dir}/schemas.json', ds)

   orders = spark.read.csv(f'{base_dir}/{ds}',inferSchema=True).toDF(*columns)

   orders. \
   write. \
   mode('overwrite'). \
   parquet(f'{tgt_base_dir}/{ds}')
```

Each dataset is written under `retail_db_parquet` using its dataset name, for example:

- `.../retail_db_parquet/departments`
- `.../retail_db_parquet/orders`
- `.../retail_db_parquet/order_items`

The variable is still named `orders` in the loop, as in the provided code; on each iteration it refers to the DataFrame for the current value of `ds`.
