# Save Query Results to a Unity Catalog Volume as Parquet

This guide saves a Spark SQL query result as Parquet files in a Unity Catalog volume, checks that the output exists, and reads it back with SQL.

> **Before you start:** The temporary views `orders` and `order_items` must already exist in the current notebook session. If you restarted the notebook or compute, rerun the cells that create those views.

## 1. Write the query result as Parquet

Run this in a Databricks SQL notebook cell:

```sql
INSERT OVERWRITE DIRECTORY '/Volumes/workspace/default/retail_db/retail_db/daily_product_revenue'
USING PARQUET
SELECT
  o.order_date,
  oi.order_item_product_id,
  ROUND(SUM(oi.order_item_subtotal), 2) AS revenue
FROM orders AS o
JOIN order_items AS oi
  ON o.order_id = oi.order_item_order_id
WHERE o.order_status IN ('COMPLETE', 'CLOSED')
GROUP BY
  o.order_date,
  oi.order_item_product_id;
```

This query:

- Joins each order item to its order.
- Keeps orders with status `COMPLETE` or `CLOSED`.
- Adds up item subtotals for each order date and product.
- Writes the result in Parquet format to the `daily_product_revenue` folder in the volume.

### What does `INSERT OVERWRITE DIRECTORY` do?

It writes the query result to the destination directory. **If that directory already contains output from an earlier run, it is replaced.** Use a new destination folder if you need to keep the previous output.

Spark may create several Parquet part-files inside the folder rather than one file. That is normal: Spark writes output in parallel.

## 2. Check that the Parquet output exists

Run this in a notebook cell:

```text
%fs ls /Volumes/workspace/default/retail_db/retail_db/daily_product_revenue/
```

You should see one or more Parquet files, often with names beginning with `part-`.

`%fs ls` is a Databricks notebook command. Run it in a notebook cell, not in Mac Terminal.

## 3. Query the saved Parquet data

Run this in a SQL cell:

```sql
SELECT *
FROM parquet.`/Volumes/workspace/default/retail_db/retail_db/daily_product_revenue/`
ORDER BY order_date, revenue DESC;
```

This reads the Parquet files from the volume folder and sorts the results by date, then by revenue from highest to lowest.

## Key terms

- **Parquet** is a columnar file format commonly used for analytics. It preserves column types and is efficient for Spark to query.
- **Volume** is a Unity Catalog-managed location for files. The path follows `/Volumes/<catalog>/<schema>/<volume>/<folder>`.
- **Directory output** is a folder containing Spark's output files, not necessarily one file.
