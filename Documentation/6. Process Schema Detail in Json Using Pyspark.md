# Read and Explore `schemas.json` in Databricks

This guide checks that `schemas.json` is in a Unity Catalog volume, reads its text, parses it as JSON, and extracts the column names for the `orders` table.

> Run the Python and `%fs` examples in Databricks notebook cells. They are not Mac Terminal commands.

## File location

The file is expected here:

```text
/Volumes/workspace/default/retail_db/retail_db/schemas.json
```

A volume path has this structure:

```text
/Volumes/<catalog>/<schema>/<volume>/<folder-or-file>
```

In this example, `workspace` is the catalog, `default` is the schema, `retail_db` is the volume, and `retail_db/schemas.json` is the folder and file inside the volume.

---

## 1. Check whether the file is there

List the folder that contains the file:

```text
%fs ls /Volumes/workspace/default/retail_db/retail_db/
```

Look for `schemas.json` in the results. `%fs ls` lists folder contents. It is more useful to list the parent folder than to list the file path itself.

You can also check using Python:

```python
files = dbutils.fs.ls("/Volumes/workspace/default/retail_db/retail_db/")
[file.name for file in files]
```

To return `True` or `False` for whether the file appears in that listing:

```python
any(file.name == "schemas.json" for file in files)
```

---

## 2. Read the file as raw text with SQL

```sql
SELECT *
FROM text.`/Volumes/workspace/default/retail_db/retail_db/schemas.json`;
```

The `text` data source treats each line as text and returns a column named `value`. If the JSON is formatted across several lines, this query returns one row per line. It does not parse JSON fields yet.

---

## 3. Inspect the `spark.read.text()` help

In a Python notebook cell, run:

```python
help(spark.read.text)
```

This displays the function's documentation and parameters. One parameter is `wholetext`:

- `wholetext=False` (the default) reads a text file as one row per line.
- `wholetext=True` reads each file as one row containing the entire file contents.

For a JSON document that spans multiple lines, `wholetext=True` is convenient because it gives `json.loads()` the complete JSON string at once.

---

## 4. Read the entire JSON file as one string

```python
schemas_text = (
    spark.read
         .text(
             "/Volumes/workspace/default/retail_db/retail_db/schemas.json",
             wholetext=True
         )
         .first()
         .value
)

schemas_text
```

What happens here:

1. `spark.read.text(...)` reads the file as text.
2. `wholetext=True` puts the full contents of each file into one row.
3. `.first()` takes the first row from the result.
4. `.value` gets the string from that row's `value` column.
5. `schemas_text` now contains the raw JSON text.

This example uses one exact file path. If you use a wildcard that matches multiple files, `.first()` returns only one of those file contents.

---

## 5. Parse the text as JSON and inspect its top-level keys

```python
import json

schema_data = json.loads(schemas_text)
schema_data.keys()
```

`json.loads()` converts the JSON string into normal Python data structures—usually dictionaries and lists. `.keys()` lists the top-level dictionary keys. In this dataset, those keys are expected to be table names such as `orders`.

You can list them as a regular Python list:

```python
list(schema_data.keys())
```

---

## 6. Get the column details for `orders`

```python
columns_detail = schema_data["orders"]
columns_detail
```

This selects the value stored under the `orders` key. It is expected to be a list of dictionaries, with details for each column, such as its name and position.

For example, an individual entry might look like this:

```python
{"column_name": "order_id", "column_position": 1}
```

The exact keys and values depend on the contents of your `schemas.json` file.

---

## 7. Sort columns into their original order

```python
columns_in_order = sorted(
    columns_detail,
    key=lambda col: col["column_position"]
)

columns_in_order
```

`sorted()` returns a new list in ascending order. The `key` function tells Python which value to use for sorting: here, `column_position`.

To return only the column names in that order:

```python
[
    col["column_name"]
    for col in sorted(columns_detail, key=lambda col: col["column_position"])
]
```

This is a list comprehension: it goes through each sorted column dictionary and collects its `column_name` value.

---

## All steps together

```python
import json

schemas_text = (
    spark.read
         .text(
             "/Volumes/workspace/default/retail_db/retail_db/schemas.json",
             wholetext=True
         )
         .first()
         .value
)

schema_data = json.loads(schemas_text)
columns_detail = schema_data["orders"]

order_column_names = [
    col["column_name"]
    for col in sorted(columns_detail, key=lambda col: col["column_position"])
]

order_column_names
```

The final result is a Python list of the `orders` column names in the order described by the JSON metadata.

## Common errors

- **Path not found:** Confirm `schemas.json` appears when you list `/Volumes/workspace/default/retail_db/retail_db/`.
- **`KeyError: 'orders'`:** Check `schema_data.keys()`; the table may use a different key or capitalization.
- **JSON decode error:** Confirm the file contains valid JSON and that `schemas_text` contains the complete file. Use `wholetext=True` for a multi-line JSON document.
- **`KeyError: 'column_position'` or `'column_name'`:** Inspect `columns_detail`; the JSON may use different property names.
