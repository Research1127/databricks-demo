# Process Data with Databricks Spark SQL

This guide shows how to run SQL in a Databricks notebook, read the `orders` CSV files from your Unity Catalog volume, and count orders by status.

> The examples use the volume path `/Volumes/workspace/default/retail_db/retail_db`. They assume the `orders` CSV files do not have a header row, so the column names and types are provided below.

## 1. Run a SQL query in a notebook

There are two common ways to run Spark SQL.

### Option A: Use a SQL notebook cell

Create a notebook cell and choose **SQL** as its language. Run:

```sql
SELECT current_date();
```

If you are using a Python notebook, start the cell with `%sql` to run SQL in that cell:

```sql
%sql
SELECT current_date();
```

### Option B: Run SQL from Python

In a Python notebook cell, pass the SQL statement to `spark.sql()`:

```python
spark.sql("SELECT current_date()").show()
```

`show()` prints the query result in the cell output.

## 2. Check that the files are in the volume

In a notebook cell, run:

```text
%fs ls /Volumes/workspace/default/retail_db/retail_db/orders/
```

This lists the files in the `orders` folder. `%fs` is a Databricks notebook command for file-system operations. It runs in a notebook cell, not in your Mac Terminal.

If you prefer, use Python in a notebook cell:

```python
display(dbutils.fs.ls("/Volumes/workspace/default/retail_db/retail_db/orders/"))
```

`dbutils.fs.ls()` lists the folder contents, and `display()` shows them in a readable table.

---

## 3. Create a temporary view for the CSV files

A **view** gives the files a name that you can query with SQL. This temporary view is called `orders`. It exists for the current notebook session; it does not create a permanent table or copy the data.

Run this in a SQL cell (or in a Python notebook cell with the `%sql` magic):

```sql
CREATE OR REPLACE TEMPORARY VIEW orders (
  order_id INT,
  order_date STRING,
  order_customer_id INT,
  order_status STRING
)
USING CSV
OPTIONS (
  path '/Volumes/workspace/default/retail_db/retail_db/orders'
);
```

The column definitions tell Spark how to name and interpret each field in the CSV. The `path` tells Spark where the files are stored in the volume.

If your CSV files have a header row, add this option inside `OPTIONS`:

```sql
header 'true'
```

For example:

```sql
OPTIONS (
  path '/Volumes/workspace/default/retail_db/retail_db/orders',
  header 'true'
);
```

---

## 4. Preview the data

Run in a SQL cell:

```sql
SELECT *
FROM orders
LIMIT 10;
```

This displays up to ten rows so you can check that the columns were read correctly.

---

## 5. Count orders by status

Run:

```sql
SELECT
  order_status,
  COUNT(*) AS order_count
FROM orders
GROUP BY order_status
ORDER BY order_count DESC;
```

This groups the rows by `order_status`, counts the rows in each group, and sorts the largest counts first.

## Quick reminder

- Use a **SQL cell** or `%sql` to write SQL statements.
- Use `spark.sql("...")` to run SQL from a **Python cell**.
- Use `/Volumes/catalog/schema/volume/...` to access files in a Unity Catalog volume.
- A temporary view is for querying during your session. Use a Unity Catalog table when you need data registered for reuse.
